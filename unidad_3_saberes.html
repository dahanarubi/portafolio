Temas de la Unidad

En esta unidad se estudian los frameworks para el desarrollo de interfaces de programación de aplicaciones (API) y la implementación de APIs para aplicaciones orientadas a servicios.

1. Frameworks para desarrollo de APIs

Los frameworks proporcionan herramientas y estructuras que facilitan el desarrollo de APIs eficientes, escalables y seguras.

  • Flask, Django, Express, Spring Boot.
  • Estandarización y aceleración del desarrollo.
  • Mantenibilidad y buenas prácticas.

2. Desarrollo de una API

Crear una API implica definir endpoints, métodos HTTP y asegurar la comunicación entre aplicaciones o servicios.

  • Diseño y documentación de la API.
  • Implementación de rutas y endpoints.
  • Pruebas, seguridad y consumo de la API.

3. Identificación de frameworks en aplicaciones orientadas a servicios

Reconocer los frameworks más usados permite seleccionar la herramienta correcta según la necesidad del proyecto y los servicios que se desean implementar.

  • Comparación de frameworks según rendimiento y escalabilidad.
  • Selección de frameworks según tipo de servicio.

4. Proceso de desarrollo de APIs

El proceso de desarrollo de una API sigue pasos claros desde el diseño hasta la implementación y pruebas.

  • Planeación y análisis de requerimientos.
  • Diseño de endpoints y rutas.
  • Implementación y pruebas unitarias.
  • Documentación y mantenimiento.
